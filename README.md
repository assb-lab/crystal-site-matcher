# Crystal Site Matcher

CIF ファイルの結晶構造で、あるサイトのイオンを別のイオンに置き換えたときに「入りそうかどうか」を、配位多面体の結合距離とシャノンのイオン半径から見積もる Web アプリです。イオン伝導体の解析に使える構造特徴量（BVSE 浸透障壁、空隙のボトルネック、可動イオン副格子、多面体の連結など）を計算し、複数の構造をグラフで比較できます。ビルドすると HTML 1 ファイル（`dist/index.html`）になり、サーバーなしでブラウザで開けます。

ソースコード: [Crystal Site Matcher（GitHub）](https://github.com/assb-lab/crystal-site-matcher)。アプリ上部のテーマ切り替えの右側にある GitHub アイコンから新しいタブで開けます。

## 使い方

初めて開いたときは、できることと基本操作を 6 ページで説明する案内が表示されます（「スキップ」で閉じられます）。表示済みかどうかはブラウザの localStorage に保存し、あとからは右上の「?」ボタンで開き直せます。

起動時は LGPS（Li₁₀GeP₂S₁₂）が先頭・選択状態で開き、LiFePO₄・LiCoO₂・Li₃N・α-AgIの計5材料を表示します。初期タブは「構造と結合」で、BVSE計算は開始しません。

0. **左の縦タブ**に開いている構造がサムネイル付きで並びます。複数ファイル・複数データブロックの CIF をまとめて開けます（1 ブロック = 1 構造）。上の「比較」で比較モードに切り替え、チェックで対象を選びます。
1. 「CIF を開く」かドラッグ＆ドロップで CIF を読み込む（サンプル 10 種あり）。「サンプルを開く」から構造を選ぶか「すべて開く」でまとめて追加できます。展開メニューはテーマに対応し、矢印キー・Home/End・Enterで選択、Escapeや外側クリックで閉じられます。
2. 3D 表示で原子をクリックしてサイトを選ぶ。ドラッグで回転、右ドラッグで平行移動（従来の半分の速度で細かく調整）、ホイールで拡大。a / b / c / a* / b* / c* ボタンで軸方向から表示。
   - 部分占有・混合占有のサイトは、球を占有率の円グラフとして色分けします。同じ元素の占有率は合算し、1に足りない分は空孔として白く表示します（CIF の値の丸めとして、1 行あたり 0.005 までの不足は満席とみなします）。視点を変えても分率が読み取れ、サムネイルにも反映されます。「表示設定」に凡例、球のツールチップに分率を表示します。区画の向きは原子配列の方向を表すものではありません。過占有の場合は表示だけを正規化し、計算用の占有率は変更しません。
   - 「表示設定 → 多面体」で、元素ごとに描く多面体の中心をカチオン／アニオンで切り替えられる（アニオン中心なら Li₃N の NLi₈ など）。
3. **サイト解析** タブ
   - 距離ストリップ上の線をドラッグするか「＋殻 / −殻」で結合距離の上限を変えると、配位数と多面体（3D 表示も）が切り替わる。
   - 適用範囲は「元素ペア全体」か「このサイトのみ」。
   - 配位数、多面体の形（理想多面体との CShM）、歪み指数、ECoN、二次伸長、結合角分散、BVS を表示。
   - 「多面体の形と歪み」には、結合長の平均・最大・最小と、中心原子と配位子の重心のずれ（オフセンターの大きさ）も表示。
   - サイトの空間半径 r_site = ⟨d − r_X⟩（r_X は配位子自身の配位数でのシャノン半径）とホストイオンのシャノン半径を比較。
4. **置換候補** タブ
   - シャノン表の全イオンを、同じ配位数での半径・BVS・価数差から採点してランキング。
   - イオン半径マップ、任意イオンの詳細評価、許容幅や価数フィルタの調整ができる。
5. **特徴量** タブ
   - 可動イオン（既定は Li → Na → K → Ag → Cu → Mg … の順で最初に見つかったもの）、ホップ距離の上限、BVSE グリッド間隔を設定。
   - BVSE エネルギー地形（体積分率 vs ΔE と 1D/2D/3D 浸透障壁）。3D 表示に等エネルギー面を重ねられる。
   - 空隙（骨格イオン表面からの距離）の体積分率と浸透半径、可動イオン間ホップのボトルネック半径（3D 表示可）。
   - ホップの散布図は等価なホップを 1 点にまとめ、点か一覧の行をクリックすると、その経路を 3D 表示に動く破線で示す（両端の可動イオンとボトルネックの位置も表示）。経路はボトルネック半径を求めた折れ線（1 回だけ曲がる）で、「3D に表示」の全ホップはサイト間の直線で表示する。
     経路の帯はボトルネックの色を保ち、破線だけがライト／ダークテーマの文字色に追従する。
   - 多面体の連結（頂点・稜・面共有）、サイトごとの BVS とサイトエネルギー、特徴量の一覧（TSV コピー）。
   - **回折・g(r)** タブ: 元素ペアごとの部分動径分布関数 g(r) と計算粉末 XRD（Cu Kα₁）。原子配置だけから決まるので、開いたときにその構造の分だけ計算し、BVSE など特徴量の計算は始まりません。酸化数や結合の設定を変えても再計算しません。
6. **比較モード**
   - 特徴量の棒グラフ、2 つの特徴量の散布図、曲線の重ね描き（BVSE / 空隙の体積分率、部分 g(r)、XRD）、全特徴量の表。CSV のコピー・保存。g(r) と XRD は、その重ね描きを選んだときだけ計算します。
7. **構造と結合** タブ（起動時に開くタブ）
   - 酸化数の確認・修正（CIF に無ければ電荷中性から推定）、元素ペアごとの結合判定距離（初期値は VESTA と同じ）。
   - 重い特徴量計算（BVSE グリッドなど）は「特徴量」タブか比較モードを開いたときだけ実行します。
8. **表示言語とテーマ**: 右上で日本語 / English、システム / ライト / ダークを切り替えられます。選択はブラウザに保存され、言語の初期値はブラウザの言語設定に従います。CSV の見出しと値は言語設定によらず英語で出力します。

## コマンドライン（特徴量の一括計算）

アプリと同じ計算コードで、多数の CIF の特徴量をまとめて計算できます。`dist/csm-features.mjs` は依存パッケージなしで Node.js（20.19 以上）だけで動く 1 ファイルです。

```bash
node dist/csm-features.mjs cifs/*.cif -o features.csv   # features.csv, features.hops.csv, features.sites.csv
node dist/csm-features.mjs cifs/ -r --no-grid -o quick.tsv   # ディレクトリを再帰的に、グリッド計算なしで高速に
node dist/csm-features.mjs LiCoO2.cif -f json               # JSON（ホップも各構造に含む）
node dist/csm-features.mjs --list-features                  # 特徴量のキー・単位・説明
pnpm features cifs/*.cif -o features.csv                   # pnpm から（同じ処理）
```

- 1 データブロック = 1 行。列は `file, block, formula, ox_guessed` と各特徴量のキー（`--list-features` で一覧）。見出しと値は英語で出力し、数値は有効数字 8 桁です。
- **可動イオン間ホップ**: 可動イオンを含む構造では、ホップごとの距離 `d` とボトルネック半径 `rb`、始点・終点・ボトルネック・経路の曲がる点（`via`）の分率座標を自動で出力します（グリッドを計算したときは鞍点のエネルギー `E_saddle` と往・復の障壁 `barrier_fwd` / `barrier_rev` も）。CSV/TSV では `<出力名>.hops.csv` に、JSON では各構造の `hops` に入ります。可動イオンはアプリと同じ規則で選びます（Li → Na → K → Ag → Cu → Mg → Zn → Ca → Rb → Cs → H の陽イオン、それがなければ F・O の陰イオン）。`--mobile Na` で指定、`--mobile none` で無効、`--no-hops` でホップの出力だけを止められます。
- **BVSE の安定サイト**: グリッドを計算すると、BVSE 地形の極小点（CIF のサイトか空きサイト候補か、エネルギー、分率座標、最寄りの CIF サイトと距離、曲率）を出力します。CSV/TSV では `<出力名>.sites.csv` に、JSON では各構造の `sites` に入ります。`--no-sites` で止められます。
- 計算条件: `--ox "Co=3,O1=-2"`（元素またはサイトラベルごとの酸化数）、`--hop-cutoff 4`、`--grid 0.2`（BVSE / 空隙グリッドの間隔, Å）、`--no-grid`（E_*, R_*, maxVoid, siteE_* を省略）。
- 複数ファイルは CPU 数まで並列に計算します（`-j` で変更）。読めないファイルがあっても残りを計算し、エラーを標準エラーに出して終了コード 1 で終わります。

## 判定の考え方

| 指標 | 内容 |
| --- | --- |
| サイズ | Δr = (r_M − r_site)/r_site、S_size = exp(−½(Δr/σ)²)、σ は既定 15% |
| BVS | V = Σ exp((R₀ − d_i)/0.37)（Brese & O'Keeffe 1991）、S_BVS = exp(−½((V/\|q\| − 1)/0.25)²) |
| 価数差 | Δq = 0 → 1、±1 → 0.75、±2 → 0.5、それ以上 → 0.3 |
| 総合 | 重み付き幾何平均（0.6 / 0.25 / 0.15）× 100。75 以上「入りやすい」、50 以上「可能性あり」、25 以上「条件次第」 |

表に無い配位数の半径は隣接 CN から内挿（既定では外挿・代用値は除外）。結晶場安定化や共有結合性などは考慮しない幾何学的な目安です。

## 特徴量

| 分類 | 主な特徴量 |
| --- | --- |
| 格子と対称性 | a, b, c, α, β, γ, c/a, V, V/Z, V/N, 密度, 空間群, 晶系, 独立サイト数, 構造情報量 I_G（Krivovichev） |
| 充填とアニオン骨格 | 充填率（シャノン半径）, 陰イオンあたり体積, 陰イオン間最近接距離, アニオン副格子の型（bcc/fcc/hcp との CShM）, Δχ |
| 結合原子価 | GII, 可動イオンの BVS とその不整合 |
| 可動イオン副格子 | 数・数密度, 独立サイト数, 空孔率, 占有エントロピー, 平均 CN, 平均距離, 多面体体積・歪み, 可動–可動 / 可動–骨格陽イオンの最近接距離 |
| ホップ経路 | ホップ次数, ホップ網の次元, ボトルネック半径（最小・平均）, 1D/2D/3D と a/b/c 軸方向に通じる最大ボトルネック半径 |
| 多面体の連結 | 骨格の頂点・稜・面共有の割合, 孤立多面体の割合, 可動–可動 / 可動–骨格の面共有割合 |
| アニオン環境 | 孤立アニオン（骨格陽イオンと結合しないアニオン）の割合・数密度・最近接距離・配位数・かごの CShM, アニオンのイオンポテンシャル z/r（平均・サイト間の差・孤立アニオンの平均とサイト間の差）, アニオンの CN |
| サイトのばらつきと局所の非対称性 | 可動イオンサイトの CN・結合長・歪み・CShM の最小/最大/標準偏差, 四面体・八面体サイトの割合（可動イオン・骨格）, 重心のずれ, BVVS（結合原子価ベクトル和） |
| 混合サイト | 骨格陽イオン・アニオンサイトの混合エントロピー, 半径と電荷の不均一性 |
| BVSE と空隙 | 1D/2D/3D と a/b/c 軸方向の浸透障壁・軸間の差, サイトエネルギーの分散と幅, 1D/2D/3D と a/b/c 軸方向の浸透半径, 最大空隙半径, 連結した低エネルギー体積とその割合, BVSE の安定サイト（空きサイト候補の数・数密度・最低エネルギー, 安定サイト間の距離とエネルギーの広がり, サイトの曲率と異方性, CIF サイトの再現率）, ホップごとの BVSE 障壁（最小・平均・ばらつき, 両端の非対称性, ホップ網が 1D/2D/3D・a/b/c 軸方向につながる鞍点エネルギー, トラップ深さ, 律速の窓をふさいだときの迂回経路）, 希薄極限の拡散テンソル（平均・a/b/c 軸方向・次元・異方性・実効活性化エネルギー） |

- **BVSE** は BVlain / softBV と同じ式（対イオンとの Morse 型項 + 同符号イオンとの遮蔽クーロン項, f = 0.74）をグリッド上で計算し、低エネルギー領域が周期的につながる（巻き付きベクトルの階数 1/2/3）最小エネルギーを浸透障壁としています。LiFePO₄ で E_1D ≈ 0.43 eV（BVlain の例 0.44 eV）。部分占有は占有率で重み付けした平均場近似です。
- **結晶軸方向の浸透**（`E_a` / `R_a` / `rb_a` / `E_hop_a` など）は、つながったクラスタの巻き付きベクトルの格子に格子ベクトル a（b, c）の整数倍が含まれた時点の値です。[110] など斜め方向だけにつながる 1D チャネルはどの軸にも数えず、3D につながれば 3 軸とも開きます。LGPS では E_c = E_1D（c 軸チャネル）< E_a = E_b = E_3D、LiFePO₄ では E_b = E_1D です。空隙の `R_a` などは CAVD（He et al., *Sci. Data* 7, 153 (2020)）の R_Ta などに相当し、Li₃N では R_a = R_b > R_c になります。
- **空隙** は各点から骨格イオン（可動イオン以外）のシャノン半径球の表面までの距離です。
- **孤立アニオン** は、可動イオン以外の陽イオンと結合していない（結合判定は「構造と結合」タブの設定どおり）アニオンです。アルジロダイトでは PS₄ を作らず Li だけに囲まれた S²⁻ / Cl⁻ に当たります。可動イオンを設定していないときは空欄です。
- **四面体・八面体サイトの割合** は CShM で最も近い理想形から判定した簡易的な部分格子フィンガープリントで、pymatgen の局所秩序パラメータ（LSOP）そのものではありません。
- **BVVS** = |Σ s_i r̂_i|（s_i は結合原子価、r̂_i は配位子への単位ベクトル）。孤立電子対のない陽イオンでは、多面体が歪んでいても小さな値になります。
- **BVSE の安定サイト** は BVSE グリッドの局所極小点を骨格イオンの場で精密化したもので、ヘッセ行列の固有値を曲率としています。CIF の可動イオン位置から 1 Å 以内ならそのサイト（ずれ・分裂を含む）、それ以外で最小値から 1 eV 以内なら空きサイト候補です。LiFePO₄ では b 軸チャネルの途中（Li から 1.8 Å、0.34 eV）、MgAl₂O₄ では空いた 16c 八面体サイトが候補として出ます。経験的なエネルギーの極小なので、実在のサイトかどうかは構造緩和などで確かめてください。曲率も力定数とは別物です。安定サイト間の最近接距離には、同じサイトの別セルの周期像も含めます。
- **ホップごとの BVSE 障壁** は、BVSE グリッド上で始点から終点まで、直線のまわりの筒（半径 max(1.5 Å, d/2)）の中を通る経路のうち最高点がいちばん低いもの（minimax 経路）の最高点を鞍点とし、両端の CIF サイトでの BVSE からの高さを往・復の障壁としています。障壁と鞍点座標はホップごとに保持し、実際の CIF の両端点のエネルギーも経路の最高値に含めます。表示では同じサイトの組・距離・ボトルネック半径のホップをまとめますが、これは対称等価性の判定ではありません。散布図は組内の鞍点エネルギーの平均、一覧は往・復それぞれの最小〜最大を示します（表示精度で一致すれば単一値）。CLI と特徴量の統計・浸透判定には各ホップの値を使います。鞍点の低い順にホップをつないで 1D/2D/3D につながるエネルギー（`E_hop_1D` など）をグリッドの浸透障壁 `E_1D` などと比べると、CIF のサイトを経由する経路だけで同じ障壁になるかがわかります。グリッドの刻みによって、連続体では対称等価なホップにも数値のばらつきが生じます。特徴量タブの散布図は縦軸を障壁に切り替えられ、3D で選んだ経路には鞍点の印（四角）が付きます。
- **トラップ深さ** は、CIF の可動イオン位置ごとに、そこから出るホップの障壁の最小値（脱出障壁）を求め、その最大値と平均を取ったものです。全可動サイトを対象にし、ホップを持たないサイト（`trap_isolated`）や接続ホップの障壁が未確定のサイト（`trap_unresolved`）があれば深さは空欄とし、該当サイト数を表示します。
- **連結した低エネルギー体積** は、E_1D + 0.2 eV 以下の領域のうち、セルを周期的に巻くクラスタに属する部分の体積分率です（`vol_conn`）。体積の計算は必要なら浸透障壁の探索上限（6 eV）を超えて E_1D + 0.2 eV まで続けます。低エネルギー領域全体に対する割合（`vol_conn_ratio`）が 1 より小さければ、行き止まりのポケットがあります（LGPS で約 0.9）。
- **迂回経路** は、ホップ網が最高次元につながるエネルギーにある各ホップの組（同じサイトの組・距離・ボトルネック半径のホップ）の鞍点を「窓」とし、鞍点がその窓から 0.5 Å 以内にあるホップをすべて除いてからつなぎ直したものです。各組を個別に除いた結果のうち、次元が最小のもの（同次元なら障壁が最大のもの）を報告するため、同じエネルギーのホップの並び順には依存しません。長いホップは短いホップと同じ窓を通ることが多いため、ホップの組ではなく窓で除きます。LGPS では 3D につながるのに +0.16 eV 余分にかかり、アルジロダイトでは窓をふさぐと Li のかごがつながらなくなります（`hop_bypass_dim` = 0）。
- **サイト再現率** は、CIF の可動イオン位置のうち 0.5 Å 以内に BVSE 極小があるものの割合です（CAVD の再現率と同じ基準）。Li₃N では Li2 の極小が層から 0.8 Å ずれるため 1 になりません。
- **グリッド間隔の影響**: LiFePO₄・LGPS・アルジロダイトで 0.15 / 0.20 / 0.25 Å を比べると、浸透障壁・ホップ網の障壁・トラップ深さは 0.06 eV 以内、`vol_conn_ratio` は 0.02 以内に収まります（`tests/robustness-fixture.mjs`）。一方、空きサイト候補の数は、アルジロダイトで 20 → 68 個（0.20 → 0.15 Å）のように浅い極小の数え方で大きく変わるので、グリッド間隔をそろえて比べてください。
- **希薄極限の拡散テンソル** は、可動イオン 1 個がホップ網の上を、速度定数 k_ij = ν₀ exp(−(E_saddle − E_i)/k_BT) で跳ぶとしたときの実効拡散テンソル D です（300 K、ν₀ = 10¹³ s⁻¹ を全ホップ共通に仮定）。
  - サイトの占有は π_i ∝ exp(−E_i/k_BT) で、鞍点が往・復で共通なので詳細つりあいを満たします。
  - 周期的なネットワークの補正関数 χ（Σ_j w_ij(Δr_ij + χ_j − χ_i) = 0）を連立一次方程式で解き、D = Σ w (Δr + Δχ)(Δr + Δχ)ᵀ とします。KMC を使わない決定論的な計算で、1D の鎖では各ホップの「直列抵抗」の和になります。
  - ホップは速度比で除外しません。正の重みを保つ星形–網目変換でネットワークを縮約し、並列経路の寄与も保持することで、極端に遅い直列ホップが律速の場合も計算します。最大固有値の 10⁻⁶ 以下の方向は「拡散しない」とします（`D_dim`）。
  - 平衡占有率の正規化には孤立サイトを含む全可動サイトの BVSE を使います。孤立サイトにも平衡確率が割り当てられ、その確率の分だけ平均拡散は小さくなります。非連結な成分間の初期分布はこの平衡分布を仮定します。
  - ホップ障壁の欠測や浮動小数点のアンダーフローがあるときは、経路を勝手に除かず計算不能（空欄）とします。全サイトが孤立している場合など、計算できて拡散がゼロなら次元は0、対数値は空欄です。
  - 例: LiFePO₄ は b 方向だけ（`D_dim` = 1, `Ea_D` ≈ E_hop_1D）、LiCoO₂ は ab 面内（2）、LGPS は c 方向が ab 面内より 1.5 桁速い、立方晶は等方的。
  - 実測の拡散係数ではありません。イオン間相互作用・占有の排他・相関因子・協奏的移動を含まず、BVSE の障壁は一般に実測の活性化エネルギーより高いので、値は構造間の相対比較に使ってください。長いホップの経路が短いホップと同じ窓を通る場合、並列の経路として重複して数えます。
- **混合サイト** の量は平均構造の占有率から求める理想混合の値で、短距離秩序は反映しません。混合エントロピーは同じ位置の占有率を元素ごとに合算して求めるため、同じ元素を複数の CIF 行に分けても変わりません。
- **ホップのボトルネック半径** は、可動イオンサイト間を 1 回だけ曲がって結ぶ経路 A→P→B のうち、通れる球が最大になるものの半径です（#62）。
  - 各区間の値は、骨格イオンのシャノン半径球の表面までの最短距離で、厳密に計算します。
  - 曲がる点 P は、ホップを直径とする球の中で探します。経路の長さは最大で √2·d で、BVSE 障壁を探す筒の内側に収まります。
  - P = 中点が直線なので、直線より狭くなることはありません。直線では陰イオンの球をかすめて 0 になっていた長いホップ（LGPS の Li1–Li2 3.59 Å など）も、陰イオンを避ける経路の値になります。LiCoO₂ の Li–Li は四面体サイトを経由する経路で 0.338 Å（直線では 0.148 Å）です。
  - 対称操作で重なるホップは 1 本だけ探索し、ほかは写して同じ値にします。対称操作のない CIF でも、等価なホップは 10⁻⁶ Å 以内で一致します。
  - それでも球より狭ければ 0 で、負にはなりません。2 回以上曲がる経路は考えないため、窓を 2 つ通るような経路では小さめに出ます。
  - 直線が骨格イオンの中心付近（半径の半分以内）を通る組（Li₃N の Li–N–Li、SrTiO₃ の O–Ti–O など）は、別の原子をまたぐ経路なのでホップに数えません。この判定は直線で行います。
- いずれも静的な平均構造に基づく経験的なスクリーニング指標で、DFT-NEB の障壁や実測の活性化エネルギーとは一致しません。

CIF の格子角は、未記載・`?`・`.` のときのみ90°として扱い、不正な数値文字列はエラーにします。長さ・角度に加えて、生成した体積・逆行列などの有限性も確認し、浮動小数点のオーバーフローやアンダーフローがあるセルを計算前に拒否します。

周期境界の最短距離は、格子ごとにキャッシュしたQR分解と最近平面法による初期候補を使い、残りの距離の下限で枝刈りする球探索で求めます。強く斜交したセルでも、逆格子による巨大な直方体範囲の全走査は行いません。


## 開発

パッケージマネージャーは **pnpm（12.3.4 以上）** を使います。npm / yarn では `devEngines` の指定によりインストールが止まります。

```bash
# pnpm を用意（どれか 1 つ）: corepack enable（Node.js 24 以下に同梱）/ brew install pnpm
pnpm install
pnpm dev                 # 開発サーバー
pnpm build               # dist/index.html（アプリ）と dist/csm-features.mjs（CLI）を生成
pnpm typecheck
pnpm test                # 計算・表示（日本語・英語）・CLI のテスト
```

再配布できない CIF（ICSD など）による回帰テストは、ファイルを `tests/private/`（gitignore 済み）に置くか、環境変数 `CSM_PRIVATE_CIFS` でフォルダを指定すると `pnpm test` で実行されます。ファイルがなければスキップします。対象は `Li6PS5Cl*.cif`（ICSD 131109 で確認）と `Li10GeP2S12*.cif`（ICSD 188887 で確認）で、混合サイト・孤立アニオンの値を手計算と照合します。

UI の文字列は `src/i18n/ja.ts`（基準）と `src/i18n/en.ts` にあります。`en.ts` が `ja.ts` と同じキーを持つことは型検査（`pnpm typecheck`）で確認されます。

### 依存パッケージの安全設定（`pnpm-workspace.yaml`）

| 設定 | 内容 |
| --- | --- |
| `minimumReleaseAge: 10080` | 公開から 7 日未満のバージョンはインストールしない |
| `trustPolicy: no-downgrade` | 以前のリリースより信頼レベル（Trusted Publishing など）が下がったパッケージで失敗する |
| `blockExoticSubdeps: true` | 推移的依存に git / tarball URL を使わせない |
| `strictDepBuilds: true` + `allowBuilds` | 依存パッケージの install スクリプトは許可したもの（esbuild）だけ実行し、未確認のものがあればインストールを失敗させる |
| `engineStrict: true` | `engines` の Node.js / pnpm バージョン外では実行しない |
| `verifyStoreIntegrity: true` | ストアの内容をロックファイルのハッシュと照合する |

依存を追加・更新したら `pnpm-lock.yaml` もコミットし、CI などでは `pnpm install --frozen-lockfile` を使ってください。

技術構成: Vite + React + TypeScript + three.js（TrackballControls、ConvexGeometry）、`vite-plugin-singlefile` で 1 ファイル化。

### 参照データの再生成（Python / uv）

`src/data/*.json` は pymatgen 同梱のデータと BVlain のパラメータから、`src/samples/*.cif` は `scripts/make-samples.py` で作っています。Python の環境は [uv](https://docs.astral.sh/uv/) で、入力データはコミット SHA で固定しています。

| ファイル | 固定するもの |
| --- | --- |
| `pyproject.toml` / `uv.lock` | 依存（numpy）とそのハッシュ。`exclude-newer` で指定日時より後に公開されたものは使わない |
| `.python-version` | Python のバージョン |
| `scripts/sources.lock` | pymatgen / pymatgen-core / BVlain のリポジトリとコミット SHA |

```bash
pnpm data:fetch   # = bash scripts/fetch-sources.sh（.sources/ に固定コミットを取得）
pnpm data         # = uv run --locked scripts/build-data.py …（src/data/*.json を再生成）
pnpm samples      # = uv run --locked scripts/make-samples.py（src/samples/*.cif を再生成）
git diff --stat src/data src/samples   # 差分が出なければ再現できている
```

依存を更新するときは、`pyproject.toml` の `exclude-newer` を 7 日以上前の日時に進めてから `uv lock` を実行し、`uv.lock` をコミットします。入力データを更新するときは `scripts/sources.lock` の SHA を書き換えます。
